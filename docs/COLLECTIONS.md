# Коллекции и передача проекта

Кнопка «Коллекции» открывает отдельное рабочее место. Обычный редактор и его
сохранённые проекты остаются доступны. Коллекция содержит независимые ролики;
у каждого есть постоянный ID, название, свои настройки и одна или несколько
частей исходной записи. Части соединяются в указанном порядке, в том числе
когда следующий интервал находится раньше предыдущего в исходнике.

Откройте JSON-план агента или создайте коллекцию вручную. Принимаются нативные
`CollectionPlan`, HTTP `CollectionRequest` и переносимый документ:

```json
{
  "kind": "cutmy.collection.project",
  "version": 1,
  "source": { "title": "interview.mp4", "duration_ms": 3600000 },
  "plan": {
    "version": 1,
    "options": { "format": "mp4", "cut_mode": "accurate" },
    "clips": [
      {
        "id": "clip-01",
        "label": "Две части ответа",
        "ranges": [
          { "start_ms": 120000, "end_ms": 145000 },
          { "start_ms": 60000, "end_ms": 65000 }
        ]
      }
    ]
  },
  "rendition": "final"
}
```

JSON не даёт доступа к исходнику или чужим заданиям. Импортированный
`source_id` не используется для автоматического открытия видео. Выберите своё
сохранённое видео либо загрузите запись. Совпадение содержимого подтверждается
только отпечатком `content` с SHA-256 и размером. Отпечаток `provider` подтверждает
идентичность записи на площадке, а не её байтов. При отсутствии подтверждения
или при отличающемся отпечатке нужно явно подтвердить новую привязку. Старый
локальный `plan.input` при такой привязке очищается.

Чтобы продолжить уже запущенную агентом коллекцию с тем же ключом и заданиями,
откройте приглашение серверного проекта. Сам импорт JSON создаёт отдельный
рабочий процесс и не переносит секретный ключ агента. В приглашении доступ
ограничен одним проектом и его исходником/заданиями/файлами; обычная сессия
браузера сохраняется. Ссылка действует 10 минут, предназначена одному
получателю и даёт доступ на 24 часа. Токен удаляется из адресной строки до
запроса сессии и не сохраняется в хранилище браузера. Владелец может отозвать
доступ. Метаданные проекта хранятся 7 дней и не продлевают хранение медиа.

Выберите ролик в списке и часть под плеером. Можно менять границы, порядок
частей и роликов, добавлять и удалять части. «Посмотреть ролик» воспроизводит
части по порядку без экспорта. В настройках выбранного ролика меняются формат,
качество, режим границ, аудиодорожка и «Кадр этого клипа». Изменения кадра и
интервалов поддерживают отмену/повтор в текущей вкладке. ID не меняется при
переименовании и перестановке ролика.

«Экспортировать выбранные» сохраняет редакцию проекта и отправляет задания.
Принятые задания переживают закрытие страницы; отказ из-за занятой очереди
повторяется с сохранённым временем ожидания. Неизменённые запросы используют
прежние задания. Для неудачных, отменённых и истёкших результатов есть явный
повтор: ключ попытки сохраняется до запроса, поэтому потерянный ответ не
создаёт ещё одну попытку. При конфликте редакций ваши локальные правки
сохраняются: скачайте их или откройте серверную версию.

«Скачать проект» сохраняет переносимый документ без серверных ID ресурсов,
ключей, токенов и адресов скачивания. В меню «Для агента» доступны также
нативные план и HTTP-запрос. При возврате плана агенту сохраняйте ID клипов;
источник и секретный ключ остаются в его сохранённом состоянии. Серверное
сохранение отдельно от экспорта позволяет вернуть выбор на всю коллекцию
после обработки двух изменённых роликов.

Готовый UTF-8 SRT/VTT до 512 КБ можно открыть в «Субтитры SRT/VTT». Его
таймкоды должны относиться к исходной записи. Рядом с готовыми видео появится
скачивание отдельного файла, пересчитанного по фактической карте частей
результата. Текст хранится в текущем браузерном проекте; передавайте исходный
SRT/VTT агенту отдельно, он не включается в переносимый JSON или приглашение.
Распознавания речи и вжигания субтитров этот интерфейс не выполняет.

Удаление оригинала после экспорта в обычном редакторе остаётся прежней
пользовательской настройкой. Проект коллекции не отменяет очистку и сроки
хранения. Если медиа недоступно, план и известные результаты сохраняются;
для новой привязки скачайте проект и откройте его с доступной записью.
