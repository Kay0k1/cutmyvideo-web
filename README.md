# cutmyvideo web

Русский · [English](README.en.md)

Рабочий интерфейс [cutmy.video](https://cutmy.video) для ручного выбора моментов из видео по ссылке или загруженного видеофайла. Результат можно скачать как видео MP4 или аудио MP3. Этот репозиторий приватный; обработка медиа находится в открытом [cutmyvideo-core](https://github.com/Kay0k1/cutmyvideo-core).

## Как пользоваться

Работа разделена на четыре шага; назад можно вернуться без потери выбранных моментов.

1. **Видео.** Вставьте публичную ссылку на отдельное видео, запись стрима или клип либо выберите MP4, MOV, MKV или WebM с устройства (до лимита, указанного рядом с загрузкой; на cutmy.video — 32 ГиБ). Сайт определяет сервис, а ядро возвращает настоящее название, длительность и доступный предпросмотр.
2. **Момент.** Выберите начало и конец на шкале, отметьте границы по позиции плеера и посмотрите фрагмент. Точные поля времени и масштаб раскрываются отдельно. Поддерживаются секунды (`15`), минуты (`83:10`) и часы с миллисекундами (`01:23:10.250`).
3. **Фрагменты.** Добавьте до двенадцати моментов, подпишите и отредактируйте их. Отметьте нужные фрагменты для экспорта; доступны выбор всех, дублирование и удаление выбранных.
4. **Экспорт.** Выберите MP4 или MP3, качество и режим. Дождитесь обработки и скачайте файлы. Каждый отмеченный момент сохраняется отдельно; файлы последнего экспорта остаются доступны при изменении нового выбора.

Сайт распознаёт 15 сервисов: YouTube (включая Shorts), Twitch (записи и клипы), Rutube, TikTok, Instagram (включая Reels), Vimeo, Dailymotion, VK Видео, Facebook, X/Twitter, Reddit, Одноклассники, Bilibili, Streamable и Rumble. Также принимаются публичные HTTPS-ссылки на видеофайлы и страницы, которые умеет читать ядро. Краткие ссылки передаются на сервер для безопасного разрешения.

Поддержка сервиса не гарантирует доступ к каждому ролику: приватность, необходимость входа, региональные ограничения и изменения сайта могут помешать загрузке. В таком случае интерфейс показывает понятную ошибку и предлагает загрузить видео файлом. Каналы, плейлисты, DRM и текущие прямые эфиры не импортируются.

«Точные границы» перекодируют медиа. «Исходное качество» избегает перекодирования, но может сдвинуть границы и требует совместимых кодеков. Фактические границы указаны рядом с готовым файлом. Предпросмотр зависит от источника и возможностей браузера; ручной ввод времени остаётся доступным.

При смене видео старые моменты заменяются только после успешного открытия нового. Отклонённый файл или ссылка не стирают черновик. Файл должен содержать видеодорожку; одно переименование файла не меняет его формат.

## Возможности MVP

- Четыре отдельных шага с сохранением черновика, этапа и выбранных фрагментов при возврате и перезагрузке.
- Светлая, тёмная и системная темы; шрифт Geologica с кириллицей, загружаемый с того же сайта.
- Отдельный этап со множественным выбором интервалов и групповыми действиями; точные поля времени, общая и увеличенная шкалы, управление клавиатурой.
- Кастомные меню качества, режима и масштаба с навигацией клавиатурой, поиском по первой букве, корректным фокусом и темами.
- Настоящий плеер для совместимых файлов и встроенный YouTube-плеер; без вымышленных демоданных.
- Экспорт MP4/MP3 через общее ядро, очередь заданий, отмена и отдельное скачивание файлов, в том числе частично успешных заданий.
- Восстановление черновика и последнего задания в той же браузерной сессии.
- Русский по умолчанию и полный английский интерфейс; смена языка сохраняет выбранные фрагменты.
- Примеры, справка, настройки формата/качества/границ/масштаба по умолчанию.
- Раздел поддержки с четырьмя адресами кошельков и копированием. Приложение не выполняет переводов.
- Компактное рабочее место на компьютере: выбор одного момента без списка и настроек экспорта на том же экране; готовые файлы рядом с настройками экспорта.
- Начальный экран помещается на небольшом телефоне; редактор на телефоне идёт в обычном порядке с удобными областями нажатия. Длинные списки на компьютере прокручиваются внутри своей области.
- Видимый фокус, подписанные ползунки и ошибки с действиями для исправления.

Настройки, язык и тема сохраняются только в браузере. Срок хранения медиа и ограничения обработки определяет сервер. Для видеоплатформ и несовместимых с браузером кодеков сервер готовит короткий предпросмотр выбранного участка. Ползунок показывает время всей записи, а временные файлы удаляются после передачи. Для ссылок не требуется хранить полную копию стрима. Ограничения доступа платформ продолжают действовать.

У ползунков компактные ручки и отдельные области захвата пальцем. При захвате виден точный таймкод; клавиатура сохраняет активную границу в видимой части шкалы. Если экспорт завершился ошибкой, рядом указана причина и действие для исправления. Повтор экспорта сохраняет выбранные моменты.

## Разработка

Рекомендуется Node.js 22; минимальная поддерживаемая версия — 20.19. Нужны запущенное ядро с HTTP API на `127.0.0.1:8080` и его обработчик заданий.

```sh
npm ci
npm run dev
```

Vite слушает порт `5173` и проксирует `/api` в backend. Сайт, API, медиаплеер и скачивание используют один origin и защищённую серверную сессию.

```sh
npm run typecheck
npm test
npm run build
```

Проверки браузера используют настоящее ядро и синтетические тестовые видео:

```sh
npx playwright install --with-deps chromium firefox webkit
npm run test:e2e
```

CI сохраняет все пять проектов: Chromium и Firefox проходят проверки в Linux, а полная матрица WebKit — в macOS 15. [Playwright рекомендует macOS для проверки видео ближе к Safari](https://playwright.dev/docs/browsers#webkit). На Linux тот же проект доступен командой `xvfb-run -a --server-args='-screen 0 2560x1440x24' npm run test:e2e -- --project=layout-webkit --headed`: остановка GTK/GStreamer после перемотки пока не устранена, хотя передача исходного MP4 и диапазона байтов проверена полностью. Перенос CI не означает исправления этой проблемы Linux.

В одноразовом окружении macOS CI для `org.webkit.Playwright` включается Keyboard Navigation (`AppleKeyboardUIMode=2`), чтобы проверять реальный переход Tab между кнопками-ползунками; прежнее значение восстанавливается после теста. Это настройка браузера для проверки доступности, интерфейс сайта не меняется. [Настройка навигации Apple](https://support.apple.com/en-my/guide/mac-help/mchlc06d1059/mac), [поведение macOS WebKit в Playwright](https://github.com/microsoft/playwright/issues/41808).

Переменные запуска и проверенные сценарии описаны в [docs/QA.md](docs/QA.md). Размещение и обновления — в [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md). Dockerfile собирает статический сайт; reverse proxy маршрутизирует `/api` в ядро.

[Повторный аудит и исправления от 5 октября 2026](docs/audit-fixes-2026-10-05.md): изменения хранения, очереди, безопасности и интерфейса, схемы, измеренная нагрузка и границы проверки.

## Структура

- `src/` — редактор, плеер, шкала, API-клиент, локализация и настройки.
- `docs/UX.md` — решения интерфейса и первичные руководства W3C/GOV.UK.
- `e2e/` — интеграционные проверки в браузере.
- `deploy/` — размещение продукта на сервере.
- `CHANGELOG.md` — история изменений.

Удалённый интерфейс не содержит медиадвижок. Универсальные операции и изменения обработки развиваются в публичном ядре; этот репозиторий содержит продуктовый сайт.

## Поддержка разработки

Адреса сетей TRON, Solana, Ethereum и Bitcoin доступны в [разделе поддержки](https://cutmy.video/?panel=support). Копируйте адрес нужной сети и выполняйте перевод в своём кошельке.

## Длинные записи и фоновые задания

На cutmy.video действуют лимиты: 32 ГиБ на загружаемый файл, 12 часов на фрагмент, 24 часа и 32 фрагмента на экспорт, 16 ГиБ на готовый файл. Получение с платформ ограничено 32 ГиБ за задание. Интерфейс получает фактические настройки из API. В режиме точных границ длинные записи кодируются с ограничением битрейта; режим без перекодирования сохраняет исходные потоки и может сдвинуть начало до ключевого кадра.

Недавние 30-секундные участки предпросмотра остаются в браузере (до 8 участков / 64 МиБ); следующий участок загружается заранее. Серверный кэш повторно использует подготовленные участки после перезагрузки страницы и ограничен 512 МиБ с удалением после 30 минут без обращения. Не просмотренное ранее место требует получения и подготовки видео.

Экспорт продолжается при открытии другого видео. «Экспорты и файлы» показывает до 30 последних заданий, активные — первыми; позволяет отменять задания и скачивать сохранённые результаты. Скачивание поддерживает HTTP Range и отдельный 12-часовой срок соединения для крупных файлов. Загрузка и результаты хранятся 24 часа; активные задания защищают свои файлы от очистки.
