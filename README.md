# cutmyvideo web

Русский · [English](README.en.md)

Рабочий интерфейс [cutmy.video](https://cutmy.video) для ручного выбора и экспорта фрагментов видео и аудио. Этот репозиторий приватный; обработка медиа находится в открытом [cutmyvideo-core](https://github.com/Kay0k1/cutmyvideo-core).

## Как пользоваться

1. Вставьте публичную HTTPS-ссылку или загрузите файл с устройства. В разделе «Примеры» есть короткий ролик для проверки.
2. Выберите начало и конец на шкале либо введите точные таймкоды. Поддерживаются секунды (`15`), минуты (`83:10`) и часы с миллисекундами (`01:23:10.250`).
3. При необходимости добавьте другие фрагменты и подпишите их. Выбранный момент можно просмотреть отдельно.
4. Выберите MP4 или MP3, качество и режим нарезки. Каждый фрагмент экспортируется отдельным файлом.
5. Нажмите «Вырезать фрагмент», дождитесь обработки и скачайте результаты.

«Точные границы» перекодируют медиа. «Сохранить потоки» избегает перекодирования, но может сдвинуть границы и требует совместимых кодеков. Фактические границы указаны рядом с готовым файлом. Предпросмотр зависит от источника и возможностей браузера; ручной ввод времени остаётся доступным.

## Возможности MVP

- Несколько интервалов, точные поля времени, общая и увеличенная шкалы, управление клавиатурой.
- Настоящий плеер для совместимых файлов и встроенный YouTube-плеер; без вымышленных демоданных.
- Экспорт MP4/MP3 через общее ядро, очередь заданий, отмена и отдельное скачивание файлов, в том числе частично успешных заданий.
- Восстановление черновика и последнего задания в той же браузерной сессии.
- Русский по умолчанию и полный английский интерфейс; смена языка сохраняет выбранные фрагменты.
- Примеры, справка, настройки формата/качества/границ/масштаба по умолчанию.
- Раздел поддержки с четырьмя адресами кошельков и копированием. Приложение не выполняет переводов.
- Адаптивная компоновка, видимый фокус, подписанные ползунки и ошибки с действиями для исправления.

Настройки и выбор языка сохраняются только в браузере. Срок хранения медиа и ограничения обработки определяет сервер. Некоторые платформы ограничивают доступ с сервера или требуют входа: в таком случае можно загрузить файл.

## Разработка

Рекомендуется Node.js 22; минимальная поддерживаемая версия — 20.19. Нужны запущенное ядро с HTTP API на `127.0.0.1:8080` и его обработчик заданий.

```sh
npm ci
npm run dev
```

Vite слушает порт `5173` и проксирует `/api` в backend. Сайт, API, медиаплеер и скачивание используют один origin и защищённую серверную сессию.

```sh
npm run typecheck
npm test
npm run build
```

Проверки браузера используют настоящее ядро и синтетические тестовые видео:

```sh
npx playwright install chromium
npm run test:e2e
```

Переменные запуска и проверенные сценарии описаны в [docs/QA.md](docs/QA.md). Размещение и обновления — в [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md). Dockerfile собирает статический сайт; reverse proxy маршрутизирует `/api` в ядро.

## Структура

- `src/` — редактор, плеер, шкала, API-клиент, локализация и настройки.
- `docs/UX.md` — решения интерфейса и первичные руководства W3C/GOV.UK.
- `e2e/` — интеграционные проверки в браузере.
- `deploy/` — размещение продукта на сервере.
- `CHANGELOG.md` — история изменений.

Удалённый интерфейс не содержит медиадвижок. Универсальные операции и изменения обработки развиваются в публичном ядре; этот репозиторий содержит продуктовый сайт.

## Поддержка разработки

Адреса сетей TRON, Solana, Ethereum и Bitcoin доступны в [разделе поддержки](https://cutmy.video/?panel=support). Копируйте адрес нужной сети и выполняйте перевод в своём кошельке.
